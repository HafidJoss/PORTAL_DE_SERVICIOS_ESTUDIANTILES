# Historias de usuario

Necesidades de cada actor expresadas como «Como…, quiero…, para…». Cada historia se traza a requisitos funcionales en [03-Requisitos-funcionales.md](03-Requisitos-funcionales.md).

| ID | Historia de usuario |
| :--- | :--- |
| **HU01** | Como apoderado, quiero acceder a una vista familiar multi-hijo centralizada, para supervisar el rendimiento académico de todos mis hijos con un único perfil y credencial de acceso. |
| **HU02** | Como docente, quiero ingresar calificaciones en una cuadrícula interactiva por competencias pedagógicas, para registrar masivamente los calificativos según la escala oficial del CNEB (AD, A, B, C y vigesimal). |
| **HU03** | Como apoderado, quiero registrar solicitudes de preinscripción o traslado escolar en un formulario digital en línea las 24 horas, para postular formalmente sin realizar colas presenciales. |
| **HU04** | Como apoderado, quiero subir documentos probatorios digitalizados (DNI, partida de nacimiento, certificados de estudio) en formatos PDF o imagen de hasta 5 MB, para adjuntar los requisitos obligatorios de mi expediente. |
| **HU05** | Como personal de secretaría, quiero auditar expedientes desde una bandeja centralizada y dictaminar estados (Pendiente de Revisión, Observado, Aprobado, Rechazado) con comentarios de subsanación, para procesar las admisiones y formalizar la pre-matrícula escolar. |
| **HU06** | Como estudiante o apoderado, quiero consultar las calificaciones confirmadas por el docente y descargar la libreta escolar en PDF membretado, para llevar un seguimiento transparente de las evaluaciones periódicas. |
| **HU07** | Como personal de secretaría, quiero exportar actas de evaluación y cuadros de mérito por sección en formato Excel (.xlsx) y PDF, para disponer de información compatible para la transcripción al sistema oficial SIAGIE. |
| **HU08** | Como administrador, quiero configurar el catálogo escolar (niveles, grados, secciones y asignaturas) y asignar docentes titulares y suplentes a cursos y secciones, para que la estructura académica esté definida antes de iniciar las evaluaciones. |
| **HU09** | Como personal de secretaría, quiero controlar los estados de los periodos lectivos (Aperturado, En Evaluación, Cierre Preliminar, Consolidado), para restringir la edición de notas fuera de fecha. |
