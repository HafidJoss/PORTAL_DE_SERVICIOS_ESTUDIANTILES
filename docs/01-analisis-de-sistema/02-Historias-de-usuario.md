# Historias de usuario

Necesidades de cada actor expresadas como «Como…, quiero…, para…». Cada historia se traza a requisitos funcionales en [03-Requisitos-funcionales.md](03-Requisitos-funcionales.md). Las historias marcadas como *Pospuesta* quedan fuera del MVP y se conservan para versiones siguientes.

| ID | Historia de usuario |
| :--- | :--- |
| **HU01** | Como apoderado, quiero acceder a una vista familiar multi-hijo centralizada, para seguir de forma continua a todos mis hijos, y solo a ellos, con un único perfil y credencial de acceso. |
| **HU02** | Como docente, quiero ingresar calificaciones en una cuadrícula interactiva por competencias, para registrar masivamente los niveles de logro de la escala oficial del CNEB (AD, A, B y C). |
| **HU03** | *Pospuesta.* Como apoderado, quiero registrar solicitudes de preinscripción o traslado escolar en un formulario digital en línea las 24 horas, para postular formalmente sin realizar colas presenciales. |
| **HU04** | *Pospuesta.* Como apoderado, quiero subir documentos probatorios digitalizados (DNI, partida de nacimiento, certificados de estudio) en formatos PDF o imagen de hasta 5 MB, para adjuntar los requisitos obligatorios de mi expediente. |
| **HU05** | *Pospuesta.* Como personal de secretaría, quiero auditar expedientes desde una bandeja centralizada y dictaminar estados (Pendiente de Revisión, Observado, Aprobado, Rechazado) con comentarios de subsanación, para procesar las admisiones y formalizar la pre-matrícula escolar. |
| **HU06** | Como estudiante o apoderado, quiero consultar las calificaciones publicadas por el docente y descargar la libreta escolar en PDF membretado cuando se publique, para llevar un seguimiento transparente de las evaluaciones. |
| **HU07** | Como docente, secretaría o dirección, quiero obtener automáticamente el Excel de notas en el formato del SIAGIE y las actas preliminares, para subir el reporte al sistema oficial sin volver a digitar. |
| **HU08** | Como administrador, quiero configurar el catálogo escolar (niveles, grados, secciones, asignaturas y sus competencias) y asignar titulares, suplentes, tutores y auxiliares a cursos y secciones, para que la estructura académica esté definida antes de iniciar las evaluaciones. |
| **HU09** | Como administrador, quiero controlar los estados de cada trimestre (Aperturado, En Evaluación, Cierre Preliminar, Cerrado), para restringir la edición de notas fuera de fecha. |
| **HU10** | Como estudiante, quiero ver mis notas apenas se publiquen, así como las observaciones, conclusiones y pendientes de mis docentes, para saber cómo voy y qué debo mejorar. |
| **HU11** | Como auxiliar, quiero registrar una vez al día la asistencia de mis secciones, para dejar constancia oficial de presentes, faltas y tardanzas. |
| **HU12** | Como apoderado o estudiante, quiero consultar la asistencia registrada, para detectar a tiempo faltas y tardanzas. |
| **HU13** | Como personal de secretaría, quiero cargar la nómina del SIAGIE y asignar a cada estudiante a su sección, para que el seguimiento opere sobre los estudiantes vigentes. |
| **HU14** | Como docente, quiero registrar trabajos y calificativos a medida que avanzan las clases y que el sistema me sugiera el nivel del trimestre, para confirmar mis notas sin trabajo adicional. |
| **HU15** | Como docente, quiero enviar mensajes de tareas y recordatorios de pendientes a estudiantes y apoderados, para que sepan qué deben entregar y cuándo. |
| **HU16** | Como apoderado o estudiante, quiero ver las novedades desde mi última visita, para enterarme rápido de lo nuevo sin revisar cada sección. |
| **HU17** | Como dirección o tutor, quiero consultar el avance y la asistencia por sección, para detectar a tiempo a los estudiantes que necesitan apoyo. |
